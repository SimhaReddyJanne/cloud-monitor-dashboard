# 🌩️ Cloud Monitor Dashboard

A Flask dashboard to monitor AWS resources (EC2, S3, IAM Users) using Boto3.

## 🔧 Features
- List EC2 Instances (if any)
- Show S3 Buckets and Creation Date
- Show IAM Users and Created At timestamp
- Simple UI with live AWS data
